プライバシーポリシー

本プライバシーポリシーは、iOS 向け Web ブラウザアプリ「koko」（以下「本アプリ」）における情報の取り扱いについて説明します。

1. 収集する情報

本アプリは、ユーザーの個人情報を一切収集しません。

  • アカウント登録は不要です。
  • ブックマーク・閲覧履歴・ホーム URL 設定・テーマ設定はすべてお使いの iPhone 内の SwiftData ローカルストレージにのみ保存されます。
  • 提供者のサーバーへのデータ送信は行いません。

2. 位置情報について

本アプリは iOS の位置情報サービス（CoreLocation）には一切アクセスしません。

  • Web ページが navigator.geolocation を通じて位置情報を要求した際には、ユーザー自身が事前に設定した座標値を応答します。
  • この座標値はアプリ内で WKWebView 単位でのみ作用し、他のアプリや iOS の位置情報システムには影響を与えません。
  • 実際の端末 GPS 座標は読み取られません。

3. Web 閲覧に関する情報

本アプリは汎用 Web ブラウザであり、ユーザーが訪問したサイトへは通常の HTTP(S) 通信が発生します。

  • 訪問先のサイトにはそのサイト固有のプライバシーポリシーが適用されます。
  • 本アプリ自体は閲覧内容・URL・入力情報を収集・解析しません。

4. 第三者サービス

本アプリには分析 SDK・広告 SDK・トラッキング SDK は一切含まれていません。

5. お子様のプライバシー

本アプリは 13 歳未満のお子様を対象としたものではありません。
