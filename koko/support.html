koko — サポート

「koko」は iOS 向けのシンプルな Web ブラウザアプリです。

主な機能

  • URL バー / 戻る / 進む / リロード
  • ブックマーク（保存・一覧・編集・削除）
  • 履歴（自動記録）
  • ホーム URL 設定
  • ライト / ダーク テーマ
  • Web ページに報告する位置情報をユーザー側で管理（プライバシー / 開発テスト / GPS 不調時の代替用途）

基本の使い方

  1. アプリを起動するとホーム URL（初期値: Google）が開きます。
  2. 上部の URL バーに任意の URL を入力して移動できます。
  3. ⭐ でブックマーク追加、📖 でブックマーク一覧、🕒 で履歴、⚙ で設定を開けます。
  4. 設定からホーム URL を自由に変更できます。

よくある質問

Q. 位置情報の設定はどこから行いますか？
A. 位置情報は iOS の CoreLocation 経由では取得されません。Web ページが位置情報を要求したとき、アプリは事前にユーザーが指定した座標を応答します。具体的な座標設定方法については、アプリ内のガイドを参照してください。

Q. ブックマークや履歴はクラウドに保存されますか？
A. すべてのデータは iPhone 内にのみ保存されます。外部サーバーへの送信はありません。

Q. 広告は表示されますか？
A. 本アプリに広告や第三者のトラッキング SDK は含まれていません。
